## The line

> My smartwatch congratulated me on a 3 a.m. workout — it was just me sleepwalking to the fridge for the third time.

## How it works

`main.ts` writes that single line to `entry.txt` in the output directory
(`$MAKEFUN_OUTPUT_DIR`, falling back to a local `output/`), byte-identical
with no trailing newline.

Run it with:

```sh
node main.ts
```
